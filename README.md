# NGFW Engineer Study Reference

A free study reference for the Palo Alto Networks Certified NGFW Engineer exam, written in plain language.

https://slickrule.github.io/palo-ngfw-study-guide/

## What is inside

- Plain language explanations, organised to follow the official learning path
- Tables for settings and limits
- Diagrams for traffic flows
- A short quiz at the end of each section
- "Easy to get wrong" points and an exam angle on each topic
- A "mark as solid" button, so you can track what you are confident about

## How to use it

Open `index.html` in any browser. It works offline, apart from the fonts. A PDF copy is included as `NGFW-Study-Reference.pdf`.

## Important

- This is an **unofficial** guide. It is not affiliated with, endorsed by or sponsored by Palo Alto Networks.
- It does **not** replace the official courses or documentation. Features and limits change between releases, so check details against the current Palo Alto Networks documentation.
- It contains **no exam questions** and no exam content.
